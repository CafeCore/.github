# CafeCore

**Open-source operations platform for cafés and hospitality businesses.**

CafeCore is designed to connect the daily work of café teams through shared business rules, clear workflows, and role-appropriate web and mobile experiences.

## Current Status

CafeCore is currently in a **documentation-first product-definition phase**.

We are building and reviewing the product definition before implementation begins. The project welcomes people who can improve requirements, use cases, market research, architecture proposals, UI/UX concepts, terminology, and documentation quality.

Implementation contributions are not open yet. Backend, web, mobile, infrastructure, database, and deployment work will begin only after the requirements, architecture, shared contracts, security process, and engineering standards are approved.

## Documentation

The official documentation is maintained in [`cafecore-docs`](https://github.com/CafeCore/cafecore-docs).

It contains:

- Business Requirements Specification (BRS).
- Software Requirements Specification (SRS).
- Use cases and user stories.
- Market and domain research.
- Architecture and UI/UX proposals.
- Governance, contribution, security, conduct, and support policies.

The BRS 2.0 draft is the current governing working document. Older specifications remain available as historical reference material.

## Planned Direction

The planned MVP focuses on independent dine-in cafés and includes:

- Organization, branch, employee, role, and permission management.
- Table sessions and dine-in order entry.
- Preparation queues and service coordination.
- Payment-result recording and invoice closure.
- Discounts, cancellations, refunds, and approvals.
- Traceable operational and financial history.
- A complete web client and a focused employee mobile client.
- A self-hosted community edition.

Inventory, purchasing, delivery, loyalty, customer self-service, advanced analytics, unrestricted plugins, and commercial subscription enforcement are outside the MVP.
